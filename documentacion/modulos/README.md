# Arquitectura de módulos

Esta carpeta reúne los documentos de arquitectura funcional de los módulos de
Andromeda React. Cada módulo de `src/modulos` debe tener aquí un documento con
su mismo nombre.

Los documentos presentan el propósito, los límites, el flujo, el estado, los
contratos, las dependencias y la responsabilidad de cada archivo `.js` y `.jsx`
del módulo en un nivel alto-medio.
